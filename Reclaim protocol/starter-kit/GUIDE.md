# Reclaim Protocol Starter Kit Guide

Welcome to the Reclaim Protocol Starter Kit! This guide will help you set up your development environment, integrate Reclaim Protocol, and build a simple credential verification flow using Node.js/TypeScript.

---

## 1. Prerequisites
- Node.js (v16+ recommended)
- npm or yarn
- Git

## 2. Clone the Starter Kit
```bash
git clone <your-repo-url>
cd Reclaim protocol/starter-kit/template
```

## 3. Install Dependencies
```bash
npm install
# or
yarn install
```

## 4. Configure Environment Variables
- Copy `.env.example` to `.env` and fill in your API keys or secrets as needed.

## 5. Run the Example Verification Flow
```bash
npm start
```
- The script in `template/verifyCredential.ts` demonstrates a basic credential verification using Reclaim Protocol SDK.

## 6. Resources
- [Reclaim Protocol Docs](https://docs.reclaimprotocol.org/)
- [Reclaim Protocol SDK](https://github.com/reclaimprotocol/reclaim-sdk)
