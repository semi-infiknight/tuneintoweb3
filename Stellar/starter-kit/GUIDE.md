# Stellar Starter Kit Guide

Welcome to the Stellar Starter Kit! This guide will help you set up your development environment, issue your first asset, and build a simple dApp on Stellar using the JavaScript SDK.

---

## 1. Prerequisites
- Node.js (v16+ recommended)
- npm or yarn
- Git

## 2. Clone the Starter Kit
```bash
git clone <your-repo-url>
cd Stellar/starter-kit/template
```

## 3. Install Dependencies
```bash
npm install
# or
yarn install
```

## 4. Set Up Test Accounts
- Use the Stellar Laboratory or Friendbot to create and fund test accounts:
  - [Stellar Laboratory](https://laboratory.stellar.org/#account-creator?network=test)
  - [Friendbot](https://friendbot.stellar.org/)

## 5. Issue a Custom Asset
- Use the provided script in `template/scripts/issueAsset.js` to issue a new asset on the testnet.

## 6. Build and Run the dApp
- Use the provided frontend in `template/app` to interact with your asset and accounts.

## 7. Resources
- [Stellar Docs](https://developers.stellar.org/docs)
- [Stellar JS SDK](https://www.stellar.org/developers/js-stellar-sdk/)

---

Happy hacking on Stellar!
